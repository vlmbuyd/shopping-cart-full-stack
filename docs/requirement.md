# 장바구니 FE/BE 설계 미션 기능 명세서

| 영역                 | 기능 단위           | 유저 스토리                                                       | 비고                                                    |
| :------------------- | :------------------ | :---------------------------------------------------------------- | :------------------------------------------------------ |
| **장바구니 페이지**  | 상품 선택           | 전체 상품을 선택/해제 할 수 있다.                                 | 기본값: 진입 시 전체 선택                               |
|                      | 상품 선택           | 개별 상품을 선택/해제 할 수 있다.                                 | 1개 이상의 상품이 선택된 경우 주문 확인 버튼 활성화     |
|                      | 상품 선택           | 새로 고침 시에도 선택한 상품을 유지한다.                          |                                                         |
|                      | 상품 선택           | 주문 확인 버튼을 클릭했을 때 주문 확인 페이지로 이동한다.         | 1개 이상의 상품이 선택된 경우                           |
| **주문 확인 페이지** | 주문 상품 정보 조회 | 주문한 상품의 종류와 개수를 확인할 수 있다.                       |                                                         |
|                      | 주문 상품 정보 조회 | 주문한 각 상품의 정보를 확인할 수 있다.                           | 이름, 이미지, 금액, 개수                                |
|                      | 쿠폰 모달 호출      | 쿠폰 적용 버튼 클릭 시 쿠폰 선택 모달을 볼 수 있다.               |                                                         |
|                      | 배송지 정보 확인    | 제주도 및 도서 산간 지역 여부를 체크할 수 있다.                   |                                                         |
|                      | 결제 금액 상세 조회 | 주문 금액, 쿠폰 할인 금액, 배송비, 총 결제 금액을 확인할 수 있다. |                                                         |
|                      | 결제 프로세스 시작  | 결제하기 버튼 클릭 시 결제 확인 페이지로 이동할 수 있다.          | 결제 완료 시 주문한 상품을 장바구니에서 비움            |
| **쿠폰 선택 모달**   | 쿠폰 목록 조회      | 쿠폰 선택 모달에서 사용 가능한 쿠폰을 확인할 수 있다.             | 첫 진입 시 최적 할인 조합 선택, 조건 미달 쿠폰 비활성화 |
|                      | 쿠폰 선택           | 사용할 쿠폰을 선택할 수 있다.                                     | 최대 2개 선택 가능, 비활성화 쿠폰 선택 불가             |
|                      | 예상 할인 금액 계산 | 선택한 할인 쿠폰에 따른 할인 금액을 버튼 텍스트를 통해 확인한다.  |                                                         |
|                      | 쿠폰 적용           | 쿠폰 사용하기 버튼 클릭 시 할인된 금액을 적용하고 모달을 닫는다.  | X 버튼 클릭 시 모달 닫기                                |
| **결제 확인 페이지** | 최종 결제 내역 확인 | 결제한 상품의 종류와 수량, 총 결제금액을 확인할 수 있다.          |                                                         |
|                      | 장바구니 이동       | 장바구니로 돌아가기 버튼 클릭 시 장바구니 페이지로 돌아간다.      |                                                         |
| **상품 (API)**       | 상품 조회           | 상품 목록을 조회할 수 있다.                                       |                                                         |
|                      | 상품 삭제           | 상품을 삭제할 수 있다.                                            | 존재하지 않는 상품 삭제 시 에러 발생                    |
| **장바구니 (API)**   | 상품 조회           | 장바구니에 담긴 상품 목록을 조회할 수 있다.                       |                                                         |
|                      | 상품 수량 변경      | 장바구니 상품의 수량을 변경할 수 있다.                            | 재고 초과 시 에러, 필수 필드 누락 시 에러               |
|                      | 상품 삭제           | 장바구니에 담긴 상품을 삭제할 수 있다.                            |                                                         |
| **결제 (API)**       | 주문금액 계산       | 주문 금액을 확인할 수 있다.                                       |                                                         |
|                      | 배송비 계산         | 주문 금액에 따른 배송비를 확인할 수 있다.                         |                                                         |
|                      | 총 결제 금액 계산   | 총 결제 금액(주문 금액 + 배송비)을 확인할 수 있다.                |                                                         |
